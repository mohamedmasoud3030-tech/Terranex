# Page Content Architecture (Phase 2)

Decisions below are **product-interface decisions** made from the route inventory, the canonical UX baseline (`docs/greenfield/07_UX_INFORMATION_ARCHITECTURE.md`), and the rendered application. They do not create, imply, or authorize any business rule; every number shown must keep coming from an existing read model. Pages whose business scope is policy-blocked (`/investors`, `/statements`) keep their block.

Column meanings: **Required** = minimum to understand/decide/act; **Supporting** = lower in hierarchy or progressively disclosed; **States** = loading / empty / no-results / error / forbidden / success handling that the page must provide.

## Project level (shared shell)

Every project route renders **ProjectWorkspaceHeader** (back to project home, project name, sector · currency · reference, Arabic lifecycle badge, demo banner) and **WorkspaceNav** as a horizontally scrollable tab strip (mobile) / wrapped chip strip (desktop). Sub-areas that are separate routes but one concern (`costs`+`cash`, `funding`+`terms`) render a second-level **SectionTabs** strip.
