# مشروع TerraNex — مساحة التسويق والإدارة (Marketing Workspace)

فرع مستقل يضم مساحة عمل إدارة صفحة وتسويق ومبيعات شركة **TerraNex LLC**،
منظمة لنوعين:

- `01-Marketing/` — تسويق: الفيديوهات الجاهزة للنشر (7)، عرض المالك (فيديو + باوربوينت)، مواد الهوية (الشعار وصفحة العرض).
- `02-Management/` — إدارة: وثائق المشروع، معلومات الشركة، سجل المحتوى، خطط وأدلة النشر، دليل التفاوض مع المالك.

المستودع الرئيسي (كود التطبيق) على فرع `main` لم يُمس — هذه المساحة على فرع منفصل للمراجعة والدمج عند الحاجة.
