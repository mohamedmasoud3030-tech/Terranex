# Terranex — Documentation Index

One canonical set (portfolio rule, 2026-10-22): the files below are the only
project documentation. There is no archive folder — Git history is the
archive. Dated execution reports and audit snapshots were removed after
their standing conclusions were folded into the canonical files.
(Marketing content under `التسويق-والإدارة/` is business material, not
project documentation.)
