# 📊 القياس والتحسين

> تقارير قياس الحملات تُنشأ هنا آليًا عبر:
> ```bash
> cd "04-الإنتاج/terranex-ops" && python3 engine/measure.py --csv <نموذج.csv>
> ```
> التسمية: `قياس-الحملة-<اسم>-<YYYY-MM-DD>.md` (تُنشأ بحذف تلقائي في فحوص selfcheck المعزولة).

- قالب جمع الأرقام للفريق: `python3 engine/measure.py --template قياس.csv`
- مقارنة أسبوع بأسبوع وتحديث التعلّم: عبر `learn.py` بمعرفة الوكيل وبموافقة.
- التقارير الإدارية (غير القياسية) في `../../01-الإدارة/تقارير-إدارية/`، والتاريخية المقفولة في `../../99-الأرشيف/تقارير-تاريخية/`.
