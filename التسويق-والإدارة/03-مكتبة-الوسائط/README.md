# 📥 03-مكتبة-الوسائط — مخزن الفوتاج الخام والأصول

> نُقلت هذه المكتبة من `03-مكتبة-الوسائط/` في إعادة هيكلة 2026-11-16. خريطة النقل الكاملة: `99-الأرشيف/إعادة-الهيكلة-2026-11-16/خريطة-النقل.csv`.

## البنية
```
03-مكتبة-الوسائط/
├── وارد/            ← 🎯 دورك اليدوي الوحيد: تحط اللقطات الجديدة (موبايل) هنا بأي اسم
├── خام/YYYY-MM/     ← اللقطات المنظمة والمقبولة (مثال: خام/2026-11/…)
├── مكررات/          ← ملفات رُفضت لأن بصمتها موجودة (راجعها يدويًا، تُمسح بأمان)
└── سجل-المواد-الخام.csv  ← ينشأ تلقائيًا عند أول ingest: مصدر الحقيقة لأي لقطة (FX001+)
```

## آلية التنظيم الآلية
شغّل الوكيل: «نضّم المواد الجديدة» أو نفّذ مباشرة:
```bash
cd "التسويق-والإدارة/04-الإنتاج/terranex-ops" && python3 engine/ingest_footage.py
```
السكربت يعمل تلقائيًا: بصمة md5 ← كشف مكرر ← فحص (مدة/أبعاد/fps/صوت) ← نقل إلى
`خام/YYYY-MM/التاريخ-الاسم.mp4` ← قيد في `سجل-المواد-الخام.csv` (معرف FX001-FX999، حالة «متاح»).

## سجلات المصادر والحقوق
- `خام/2026-11/manifest.json` — بيان الأصول المستلمة (المصدر، التاريخ، حالة المراجعة).
- `خام/2026-11/مراجعة-خصوصية-وموافقات/` — لقطات قيد مراجعة الخصوصية، لا تُستخدم للنشر.
- الأصول المستهلكة تُعلَّم في سجل الخام بحالة «مستخدم» + اسم المنشور.

## قاعدة لا تُكسر
قبل بناء أي منشور، الوكيل يعلّم اللقطة «مستخدم» في السجل باسم المنشور. ممنوع إعادة
استخدام نفس اللقطة لمنشورين (نفس قاعدة «مصدر واحد لكل منشور» على المستوى الخام).
محتوى الصفحة = تصوير الشركة الحقيقي فقط (B4 في قواعد الامتثال).
