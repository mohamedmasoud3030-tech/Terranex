# 📁 التسويق والإدارة — TerraNex

مجلد التسويق والإدارة الخاص بشركة TerraNex داخل هذا المشروع — منفصل تمامًا عن كود التطبيق.

## 📣 تسويق
- `تسويق/فيديوهات-جاهزة-للنشر/` — **7 فيديوهات معتمدة** موحّدة تقنيًا (yuv420p)، نسخة واحدة رسمية من كل فيديو.
- `تسويق/عرض-المالك/` — فيديو العرض + الباوربوينت.
- `تسويق/مواد-وهوية/` — الشعار الرسمي، صفحة العرض، و`terranex-ops/` (محرك الإنتاج والمهارة الرسمية الوحيدة v2.0.0).

## 🗂️ إدارة
- `إدارة/وثائق-المشروع/` — ملف المشروع الرئيسي (المرجع الحاكم)، معلومات الشركة، سجل المحتوى، دليل التفاوض.
- `إدارة/خطط-النشر/` — أدلة النشر والكابشنات.
- `إدارة/مهارات-الوكلاء/` — فهرس نظام المهارات (المحرك الفعلي داخل terranex-ops).
- `إدارة/تقارير-ومتابعة/` — تقارير الاستلام والاسترجاع والمتابعة.

## قواعد ثابتة
مواد الشركة الحقيقية فقط لمحتوى الصفحة (استثناءات محددة بالطلب المباشر في compliance)،
نسخة واحدة من كل مصدر، ولا وعود أرباح. آخر تنقية شاملة: 19 أكتوبر 2026.
