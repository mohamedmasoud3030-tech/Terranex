# 📁 التسويق والإدارة — TerraNex

هذا هو **مجلد التسويق والإدارة** الخاص بشركة TerraNex داخل هذا المشروع.
كل ما يخص إدارة الصفحة والتسويق والمبيعات موجود هنا فقط، منفصل تمامًا عن كود التطبيق.

## 📣 تسويق
- `تسويق/فيديوهات-جاهزة-للنشر/` — المجموعة المعتمدة المنظمة (7 فيديوهات، نسخة واحدة من كل فكرة/مصدر)
- `تسويق/عرض-المالك/` — فيديو العرض على المالك + العرض التقديمي
- `تسويق/مواد-وهوية/` — شعار TerraNex وصفحة العرض التفاعلية

## 🗂️ إدارة
- `إدارة/وثائق-المشروع/` — ملف المشروع الرئيسي، معلومات الشركة، سجل المحتوى، تنظيم المجموعة، دليل التفاوض مع المالك
- `إدارة/خطط-النشر/` — أدلة وخطط النشر الأسبوعية والكابشنات الجاهزة

## ملحوظة
المحتوى المنشور يعتمد على مواد الشركة الحقيقية (صور وفيديوهات صفحتها)،
بينما الأفكار والزوايا والسكريبتات جديدة في كل مرة — التفاصيل في ملف المشروع داخل قسم «إدارة».
