# 📁 التسويق والإدارة — TerraNex

مجلد التسويق والإدارة الخاص بشركة TerraNex داخل هذا المشروع — منفصل تمامًا عن كود التطبيق.

## 📣 تسويق
- `تسويق/فيديوهات-جاهزة-للنشر/` — **7 فيديوهات معتمدة** موحّدة تقنيًا (yuv420p/−15 LUFS)، نسخة واحدة رسمية.
- `تسويق/عرض-المالك/` — فيديو العرض + الباوربوينت.
- `تسويق/مواد-وهوية/` — الشعار الرسمي، صفحة العرض، و`terranex-ops/` (محرك الإنتاج والمهارة الرسمية الوحيدة — التشغيل في `OPS.md` داخله).
- `تسويق/مواد-خام/` — مخزن الفوتاج الخام: `وارد/` (تُحط اللقطات هنا) ← `ingest_footage.py` ينظمها ويمنع المكرر ويقيّد السجل.

## 🗂️ إدارة
- `إدارة/وثائق-المشروع/` — ملف المشروع الرئيسي (المرجع الحاكم)، **حالة التشغيل** (ابدأ منها)، معلومات الشركة، سجل المحتوى، دليل التفاوض.
- `إدارة/خطط-النشر/` — دليل الأسبوع الأول (محدّث 19/10) + `كابشنات/` الجاهزة للنسخ (كل واحد اجتاز critic).
- `إدارة/مهارات-الوكلاء/` — فهرس نظام المهارات (المحرك الفعلي داخل terranex-ops).
- `إدارة/تقارير-ومتابعة/` — تقارير الاستلام والاسترجاع والمتابعة.

## ⚙️ تشغيل سريع لأي جلسة
```bash
cd التسويق-والإدارة/تسويق/مواد-وهوية/terranex-ops && bash setup.sh
python engine/selfcheck.py   # يجب 11/11
```
