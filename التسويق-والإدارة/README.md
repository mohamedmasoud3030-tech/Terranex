مجلد التسويق والإدارة الخاص بشركة TerraNex داخل هذا المشروع — منفصل تمامًا عن كود التطبيق.

## البنية
| المجلد | ماذا يحتوي |
|---|---|
| **01-الإدارة/** | وثائق المشروع الحاكمة، **حالة التشغيل** (ابدأ منها)، دليل المالك، قرارات وموافقات المالك، عرض المالك، التقارير الإدارية، فهرس مهارات الوكلاء |
| **02-التسويق/** | الهوية والرسائل (الشعار الرسمي + صفحة العرض)، خطط المحتوى والنشر والكابشنات، **فهرس الحملات AD01–AD08**، القياس والتحسين |
| **03-مكتبة-الوسائط/** | «وارد» (تُحط اللقطات الجديدة هنا) ← `ingest_footage.py` ينظمها إلى «خام» ويمنع المكرر ويقيّد السجل |
| **04-الإنتاج/** | محرك `terranex-ops` كاملًا (الأوامر والاختبارات والمشاريع الإبداعية) + المعاينات الداخلية |
| **05-التسليم-والنشر/** | «جاهز-للنشر» (7 فيديوهات موحّدة تقنيًا yuv420p/−15 LUFS) + «بانتظار-مراجعة-المالك» (فيديوهات/صور تنتظر القرار + سجل الإنتاج وفهرس البصمات) |
| **99-الأرشيف/** | التقارير التاريخية المقفولة + سجل إعادة الهيكلة 2026-11-16 |
