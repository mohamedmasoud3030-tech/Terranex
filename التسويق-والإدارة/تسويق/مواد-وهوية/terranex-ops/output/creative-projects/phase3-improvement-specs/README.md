# Phase 3 — Independent Improvement Specs

هذه الحزمة مواصفات تنفيذية مستقلة فقط. لا تحتوي على رندر ولا تستبدل الأصول الأصلية.

## بوابات مشتركة

- `render_approved: false` لكل المواصفات.
- الأصل المرئي محفوظ ولا يُكتب فوقه.
- مادة الشركة الحقيقية فقط.
- `voice-00` هو الصوت الافتراضي؛ أي نص صوتي جديد يحتاج مراجعة وموافقة.
- ذكر الإسكندرية مسموح فقط داخل `campaign_local` موثق.
- `price_display_status: prohibited` لكل نسخة AD08 الحالية؛ `delivery_included_in_price: owner_confirmed` مع `delivery_coverage_status: pending_verification`، ولا يتحول ذلك إلى ادعاء في الإعلان.
- لا توجد نتائج أداء في هذه الحزمة.

## قاعدة التنفيذ

تُراجع كل مواصفة على حدة. لا يُشغّل `reel_build` أو أي محرك رندر قبل أن يغيّر المراجع المعتمد حالة `render_approved` إلى `true` في المواصفة نفسها، وبعد إغلاق بوابات الأرقام والخدمة والصوت.
