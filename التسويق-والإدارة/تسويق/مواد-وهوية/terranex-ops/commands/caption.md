# /caption — كابشن مصري + هاشتاجات

## المدخل
`{الموضوع} {المنصة} {المحور}`

## قواعد
- السطر الأول ≤ 60 حرف، فيه hook، وبيتقري لوحده قبل «شوف المزيد».
- إجمالي ≤ 220 حرف (بيتقطع في الفيد). لو المنصة لينكدإن: 600 حرف مسموح.
- CTA **واحد** بس — لو حطيت اتنين، `critic.py` بيرفض.
- 3–6 هاشتاجات: 2 ثابتة (`#TerraNex` `#استثمار_حيواني`) + 1–3 للموضوع + 1 محلية (`#الإسكندرية`).
- لهجة مصرية: «مش / عشان / بتاع / إيه / ازاي / عندنا». ممنوع: «سوف / إنّ / الذي / يُعدّ».
- ممنوع إيموجي أكتر من 4.

## المخرج — 3 نسخ بزوايا مختلفة
```
(A) خوف/تحذير:  …
(B) دليل/إثبات: …
(C) سؤال/تفاعل: …
```
+ لكل نسخة: `critic.py` score + الهاشتاجات + best-time من product-marketing §5.
