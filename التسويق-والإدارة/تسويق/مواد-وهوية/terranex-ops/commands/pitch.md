# /pitch — عرض المالك والباقات والتفاوض

> مدموج من `terranex-owner-pitch/SKILL.md` (أكتوبر 2026). المصدر الوحيد الآن هو `terranex-ops`.

## المدخل
`/pitch {نوع العرض: رسالة واتساب | PPT | صفحة تفاعلية | سكربت 60ث} {الباقة المستهدفة}`

## الهيكل الرابح (7 خطوات — لا تُختصر)
1. **هوك** — «مستثمرك اللي جاي بيدوّر عليك دلوقتي… شايف اللي ظاهر قدّامه». المنافس الظاهر بيكسب الساكت.
2. **الألم** — صفحة ساكتة = فرص بتروح كل يوم.
3. **التشخيص** — «اللي ناقصك مش منتج، اللي ناقصك ظهور يليق بحجمك».
4. **النظام** — محتوى ثقة ← إعلانات ← واتساب ← زيارة مزرعة ← عقد. إحنا نظام مبيعات مش بوستات.
5. **الإثبات** — نماذج شغل حقيقي (الفيديوهات المعتمدة 01–07) **قبل** أي كلام عن المستقبل.
6. **خطة 90 يوم** — مراحل + تقرير أرقام دوري. القرار بالأرقام لا بالوعود.
7. **الإغلاق** — سؤال واحد: «هنبدأ إمتى؟» ثم **سكوت**.

## قواعد التسعير (إلزامية)
| البند | القيمة المرجعية |
|---|---|
| باقة الانطلاقة | 8,000 ج.م/شهر |
| **الباقة الموصى بها** | **14,000 ج.م/شهر** |
| باقة النمو | 22,000 ج.م/شهر |
| ميزانية الإعلانات | **15–30 ألف، منفصلة تمامًا** وتدفع للـMeta مباشرة |

**فصل مطلق:** أتعاب الإدارة (لنا) ≠ ميزانية الإعلانات (لمنصة الإعلان). أي عرض يخلطهم = مرفوض.

> **قبل استخدام أي رقم:** راجع أحدث ملف مشروع. الأرقام أعلاه مرجعية وقابلة للتعديل بقرار المستخدم فقط.

## الممنوعات (Hard Ban)
- وعد بعائد أو ربح مضمون — بأي صيغة.
- أرقام مخترعة أو غير موثّقة في وثائق المشروع.
- خلط الأتعاب بميزانية الإعلانات في رقم واحد.
- إرسال `دليل-التفاوض-مع-المالك.md` للمالك — **ده ملف داخلي ليك بس**.

## الرد على الاعتراضات (عقود جاهزة)
| الاعتراض | الرد |
|---|---|
| «غالي» | 3 مستويات موجودة + «إحنا مش بنبيع بوستات، بنبني قناة مبيعات. مستثمر واحد يغطي التكلفة». اختر: شهر تجريبي بباقة الانطلاقة ثم قرار بالأرقام. |
| «خليني أفكر / أشوف حد تاني» | «اسأله سؤال واحد: هتقيس النجاح بإيه؟ لو قال لايكات، مش هيجيب مستثمرين. أنا هقيسه بمحادثات مؤهلة وزيارات وعقود». |
| «مفيش وقت» | اعرض النموذج التنفيذي الجاهز (أسبوع محتوى كامل منفّذ) بدل كلام. |
