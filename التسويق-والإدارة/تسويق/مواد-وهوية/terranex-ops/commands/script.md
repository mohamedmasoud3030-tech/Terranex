# /script — سكربت فيديو 20–35 ثانية

## المدخل
`{الفكرة} {المدة=25s}`

## قواعد صارمة
- 20–35 ثانية. أقل من 20 = مش هنقول حاجة. أكتر من 35 = هنفقد المشاهد.
- **ممنوع نص للصوت المولّد.** السكربت بيتكتب كـ**تعليق حقيقي** يتسجّل بصوت من الفريق.
- كل سطر لازم يقابله لقطة حقيقية متاحة (01–06). لو مفيش لقطة → اكتب «تصوير مطلوب» صراحة.
- أول 3 ثواني: hook بصري + جملة ≤ 8 كلمات.

## المخرج (beat sheet)
```
[0.0–3.0]  HOOK   | نص: … | لقطة: … | حركة: …
[3.0–9.0]  SETUP  | نص: … | لقطة: … |
[9.0–20.0] PROOF  | نص: … | لقطة: … | بيّن: الميزان/الفحص/التغذية
[20.0–25.0] CTA  | نص: … | لقطة: … | واتساب 01010154221
```
+ `script.json` بالشكل اللي `engine/make_video.py` بيقراه:
```json
{"title":"…","scenes":[{"from":0,"to":3,"headline":"…","sub":"…","stat":null}]}
```
+ سطر «الصوت»: مين بيتكلم، من أنهي ريل، وهل التسجيل موجود.

## بوّابة
- عدد الكلمات ≤ 75 كلمة لكامل السكربت (سرعة كلام طبيعية عربي ≈ 3 كلمة/ثانية).
- كل لقطة محسوبة. لا لقطة مكررة من فيديو الأسبوع اللي فات.
