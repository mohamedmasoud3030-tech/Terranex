# TerraNex Ops

نظام واحد، 6 أوامر، 4 ملفات سياق. مفيش أوامر تانية — أي طلب بيتحوّل لواحد من الستة دول.

## قبل أي حاجة — اقرأ 4 ملفات (إلزامي)
| الملف | بيحدد |
|---|---|
| `context/product-marketing.md` | الجمهور، الوعد، النبرة، أوقات النشر |
| `context/brand-kit.md` | الألوان، الخط، المقاسات، الحركة |
| `context/compliance.md` | الممنوع والمسموح وبوّابة المراجعة |
| `context/learnings.md` | اللي أثبت نفسه والـhooks المستهلكة |

لو أي ملف ناقص: **قف** واطلبه. متتخمّنش، ومتكتبش من فراغ.

## التوجيه (Router)
| الطلب | الأمر | بيستخدم | المخرج |
|---|---|---|---|
| «هنجهز إيه الأسبوع ده؟» / «أفكار» | `/idea` | learnings + pillars + منافسين | 5 أفكار مرتبة بـ3 زوايا |
| «اكتب سكربت» | `/script` | product-marketing + hook | سكربت beat-sheet بتوقيتات |
| «كابشن» | `/caption` | brand-kit + social rules | 3 نسخ + hook + هاشتاجات |
| «إعلان ممول» | `/ad` | offers + compliance | 4–6 كرييتف بأنجلز مختلفة |
| «صمّم/عدّل الفيديو» | `/edit` | brand-kit + engine | بوستر أو ريل 9:16 فعلي |
| «راجع قبل النشر» | `/review` | compliance + learnings | قرار: انشر / عدّل / ارفض |

**قاعدة التوجيه:** لو الطلب واقع بين أمرين، اختار اللي بيطلّع **ملف** مش كلام. دايمًا سلّم أصل قابل للاستخدام.

## العقود (كل أمر بيطلع نفس الشكل)
```
{نوع} · {محور من الخمسة} · {جمهور}
HOOK: سطر واحد ≤ 8 كلمات
BODY: الحد الأقصى حسب النوع
CTA: واحد بس
HASHTAGS: 3–6
SCORE: critic.py
ملاحظات: مفيش / قائمة إصلاح
```

## الحلقة (إلزامية — ده اللي بيمنع التدهور)
```
/idea → /script → /edit → /caption → /review → تسجيل في output/queue.csv
                                                ↓
                        كل جمعة: learn.py --csv → learnings.md
```
مخرج مايعدّيش `/review` **ما ينشرش**. حتى لو المستخدم مستعجل — قوله السبب بالأرقام.

## الممنوعات (ملخص تنفيذي)
- ممنوع صوت مولّد أو صورة AI تظهر كأنها من المزرعة. (قرار الشركة، وميزتنا التنافسية.)
- ممنوع وعد ربح أو نسبة مضمونة أو «بدون مخاطر».
- ممنوع رقم بلا مصدر.
- ممنوع تكرار hook مستخدم في آخر 14 يوم (راجع `learnings.md`).
- ممنوع تسليم «خطة» أو «توصية» بدل أصل قابل للنشر، إلا لو المستخدم طلب خطة صريحة.

## الأدوات المتاحة في الـengine
| الأمر | الأداة |
|---|---|
| بناء بوستر | `python engine/make_poster.py --headline "…" --stat "50" --unit "كجم" --out output/x.png` |
| بناء ريل | `python engine/make_video.py --script output/script.json --out output/x.mp4` |
| فحص كابشن | `python engine/critic.py --file copy.txt` |
| تقويم 30 يوم | `python engine/gen_calendar.py --days 30 --out output/calendar.md` |
| مقترح تعلّم | `python engine/learn.py --csv data/week.csv` |

> كل الأوامر دي deterministic: نفس المدخل = نفس المخرج، وبتشتغل **بدون أي API key**.
