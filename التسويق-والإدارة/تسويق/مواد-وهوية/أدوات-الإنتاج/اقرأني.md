# أدوات الإنتاج — TerraNex

أدوات Python deterministic، **بدون أي API key**، لتوليد المخرجات البصرية بهوية الشركة الرسمية.

## الهوية — المصدر الوحيد
| العنصر | المصدر |
|---|---|
| الشعار | `assets/logo/شعار-TerraNex.jpg` (الملف الرسمي — ممنوع أي شعار بديل) |
| الذهبي | `#D0A858` (متوسط الشعار) · لمعة `#F0D070` · غامق `#B08020` |
| الأخضر | `#225C33` (الشعار) · `#0B3D2E` · `#115E43` (صفحة العرض) |
| الخلفية | `#FBF7EC` (كريمي) |
| الخطوط | Tajawal (Black/Bold/Regular) — `assets/fonts/` |

> الألوان دي **مستخرجة بالبكسل من الشعار الرسمي**، مش تقدير.

## الأوامر
```bash
# بوستر / ستوري  (1080×1350 · 1080×1920)
python engine/make_poster.py --headline "الوزن على الطبيعة" --stat 50 --unit "كجم" \
  --sub "الخروف ده قدامك على الميزان" --out نماذج/poster.png

# موشن 9:16 من سكربت JSON
python engine/make_video.py --script script.json --out نماذج/reel.mp4

# فحص الالتزام
python engine/critic.py --file caption.txt

# تقويم (محكوم بعدد المصادر الحقيقية)
python engine/gen_calendar.py --days 7 --out calendar.md
```

## قواعد ملزمة (من ملف المشروع + البرومبت)
1. **مادة الشركة الحقيقية فقط.** الشعار من ملف الشركة، والفيديو من ريلاتها.
2. **ممنوع** تقصير ريل جاهز + عنوان فوقه. أي فيديو = فكرة + زاوية + سكريبت + ترتيب قصّ جديد.
3. **ممنوع** تكرار مصدر/فكرة. المادة الحالية = **7 مصادر → 7 منشورات كحد أقصى**.
4. **الصوت المولّد بالـAI:** بالطلب المباشر فقط، والافتراضي بشري.
5. **الصور المولّدة بالـAI:** بالطلب المباشر فقط، وممنوعة كبديل عن مادة الشركة.
6. **ممنوع** أي وعد بعائد أو ربح مضمون — `critic.py` بيرفضها آليًا.

## ملاحظات فنية
- العربي بيترسم بـPIL + libraqm (تشكيل RTL صحيح) — مش `ffmpeg drawtext`.
- `make_video.py` **مبيولّدش صوت أبدًا**؛ بياخد `--voice` من تسجيل حقيقي.
- `gen_calendar.py` بيمنع تكرار الـhooks تلقائيًا، لكنه **مش بيخلق مصادر جديدة**.
