# /idea — توليد أفكار المحتوى

## المدخل
`{المحور أو "أي حاجة"} {عدد الأفكار=5}` — مثال: `/idea دليل 5`

## قبل التنفيذ
اقرأ `context/learnings.md` (hooks مستهلكة + H1–H5) و`context/product-marketing.md` (§8 المحاور).

## الخطوات
1. اختار 3 محاور مختلفة من الخمسة (ممنوع نفس المحور مرتين في نفس الدفعة).
2. لكل فكرة، ولّد **3 زوايا**: (أ) خوف، (ب) دليل، (ج) سؤال. الزوايا هي اللي بتمنع التكرار.
3. ارفض أي فكرة:
   - الـhook بتاعها موجود في «Hooks مستهلكة» خلال 14 يوم.
   - محتاجة تصوير مش موجود (إلا لو التصوير مقرر).
   - بتوعد بربح أو نسبة.
4. رتّب بـ: قوة الدليل (40%) + سهولة التنفيذ بمصادرنا الحالية (35%) + فرقها عن المنافسين (25%).

## المخرج
```
[1] {عنوان} — محور: {…} | زاوية: {خوف/دليل/سؤال}
    HOOK: …
    ليه دلوقتي: …
    مصدر التصوير المتاح: {01–06 أو "تصوير جديد"}
    المخاطرة: {…}
```
+ في الآخر: «الـ3 hooks اللي هتتسجّل في learnings لو استخدمتها».

## مقياس النجاح
5 أفكار كل واحدة ليها مصدر تصوير **موجود فعلًا**، وصفر تكرار مع آخر 14 يوم.
