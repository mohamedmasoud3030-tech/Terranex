# /review — بوّابة ما قبل النشر

## المدخل
ملف أو نص.

## الخطوات
1. `python engine/critic.py --file {path}` → درجة 0–100 + قائمة مخالفات.
2. راجع يدويًا 3 حاجات ما بيعرفهااش السكربت:
   - هل الفيديو فيه **لقطة حقيقية** فعلية؟
   - هل الرقم اللي فيه **ليه مصدر**؟
   - هل الـhook مستخدم قبل كده في 14 يوم؟
3. القرار واحد من 3: **انشر** / **عدّل (مع 3 إصلاحات محددة)** / **ارفض (مع السبب)**.

## معايير القرار
| الحالة | القرار |
|---|---|
| درجة ≥ 85 وصفر Hard Ban | انشر |
| 70–84 أو Soft Flag | عدّل |
| < 70 أو أي Hard Ban (B1–B8) | ارفض |
| مفيش لقطة حقيقية | ارفض — حتى لو الدرجة 100 |

## المخرج
```
القرار: {انشر/عدّل/ارفض}
الدرجة: {x}/100
مخالفات: [قائمة مرقمة بالكود B1/S3/…]
الإصلاحات: [3 كحد أقصى، كل واحد قابل للتنفيذ في سطر]
```
+ بعد «انشر»: سجّل في `output/queue.csv`:
`date,time,platform,title,hook,source_clip,critic_score,status`
