# 📼 فيديوهات-المنتجة — أرشيف الإنتاج بالتاريخ

**القاعدة (محفورة 19/10 بقرار المالك):** كل يوم يُنتَج فيه فيديو جديد = **مجلد باسم تاريخ الإنتاج** `YYYY-MM-DD`، ويُسجَّل الفيديو في `سجل-الإنتاج.csv` في نفس اللحظة.

```
فيديوهات-المنتجة/
├── سجل-الإنتاج.csv          ← السجل المركزي (تاريخ/ملف/مدة/حالة)
├── 2026-10-19/              ← أول يوم إنتاج
│   ├── 09-اعلان-الشركة-المؤسسي-23ث.mp4
│   └── 09b-اعلان-الشركة-بلا-وجه-14ث.mp4
└── ...
```

## لماذا هنا وليس في `output/`؟
`output/` مستثنى من git (`output/.gitignore` يستثني `*.mp4`) — أي فيديو يُنتج هناك **يُفقد** من المستودع. هذا المجلد **متعقَّب**، فالفيديو محفوظ وله تاريخ.

## طريقة التسليم (إلزامية لأي وكيل)
```bash
A="التسويق-والإدارة/تسويق/فيديوهات-المنتجة/$(date +%F)"
mkdir -p "$A"
cp <الفيديو-النهائي> "$A/<رقم>-<اسم-واضح>-<مدة>ث.mp4"
# ثم أضف سطرًا في سجل-الإنتاج.csv بنفس التاريخ
```

## أعمدة السجل
| العمود | المعنى |
|---|---|
| `التاريخ` | تاريخ الإنتاج (اسم المجلد نفسه) |
| `الملف` | اسم الملف داخل مجلد اليوم |
| `المدة_ث` · `المقاس` · `الحجم_KB` | بيانات تقنية مقروءة من الملف نفسه |
| `المصدر` | اللقطات الحقيقية المستخدمة |
| `الصوت` | الصوت المستخدم ونوعه (بشري/مولّد/أصلي) |
| `AI` | الإضافات المولّدة إن وُجدت (§3.5) |
| `الحالة` | `جاهز` · `بانتظار-موافقة` · `موقوف` · `منشور` |
| `QA` | نتيجة `qa_video` |
| `ملاحظة` | سبب الإيقاف أو أي قيد |

> **قاعدة:** لا فيديو يُسلَّم بدون سطر في `سجل-الإنتاج.csv`، ولا حذف لأي فيديو من الأرشيف (يُوسم `موقوف` بدل الحذف — الأثر مطلوب).
