# 📥 مواد-خام — مخزن الفوتاج الخام

**دورك الوحيد اليدوي:** التصوير. تحط اللقطات الجديدة (موبايل) في `وارد/` بأي اسم.

## آلية التنظيم الآلية
شغّل الوكيل: «نضّم المواد الجديدة» أو نفّذ مباشرة:
```bash
cd terranex-ops && python3 engine/ingest_footage.py
```
السكربت يعمل تلقائيًا: بصمة md5 ← كشف مكرر ← فحص (مدة/أبعاد/fps/صوت) ← نقل إلى
`أرشيف/YYYY-MM/التاريخ-الاسم.mp4` ← قيد في `سجل-المواد-الخام.csv` (معرف FX001-FX999، حالة «متاح»).

`مكررات/` — ملفات اترفضت لأن بصمتها موجودة من قبل (راجعها يدويًا، امسحها بأمان).

## قاعدة لا تُكسر
قبل بناء أي منشور، الوكيل يعلّم اللقطة «مستخدم» في السجل باسم المنشور. ممنوع إعادة
استخدام نفس اللقطة لمنشورين (نفس قاعدة «مصدر واحد لكل منشور» على المستوى الخام).
