# 📦 05-التسليم-والنشر

| المجلد | المعنى |
|---|---|
| `جاهز-للنشر/` | الحزمة السباعية الموحّدة تقنيًا (yuv420p / −15 LUFS) + مرتبطة بدليل النشر `../02-التسويق/خطط-المحتوى-والنشر/`. حالتها الفعلية: بانتظار-موافقة في queue.csv |
| `بانتظار-مراجعة-المالك/` | كل فيديو/صورة نهائية تنتظر قرار المالك: `فيديوهات/YYYY-MM/` + `منشورات-صور/YYYY-MM/` + السجلات (`فهرس-الفيديوهات.csv` بصمات SHA-256 · `سجل-الإنتاج.csv` · `سجل-إعادة-التسمية.csv` تاريخي) |

## قواعد الحالة (دقيقة — لا تُستنتج من المكان)
- «جاهز للنشر» ≠ «منشور». **لا يوجد حاليًا أي أصل موثق كـ«منشور»**؛ عند إثبات نشر فعلي (رابط/لقطة) يُنشأ مجلد `منشور/` ويُنقل له السطر فقط.
- الموافقة على نشر أي عنصر قرار المالك — الوكيل لا يغيّر حالة «بانتظار-موافقة» إلا بطلب صريح.
- `بانتظار-مراجعة-المالك/اقرأني.md` يحوي قواعد التسمية (AD##/LIB-##/PRV##) والتسليم الإلزامية.
