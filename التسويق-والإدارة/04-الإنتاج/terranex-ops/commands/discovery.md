# Discovery — الاستكشاف الذاتي للأدوات

## متى تُفعّل (بلا طلب إذن)
1. نهاية كل مهمة موكلة إليك — وخلالها إن لمست فجوة: «لو عندنا أداة لـX لكان أسرع».
2. مرور 7 أيام تقويمية على آخر جولة (انظر تواريخ جولات المخزون).
3. عبارة المالك: «دوّر على الجديد»، «اكتشف التريندات»، «إيه أفضل الممارسات الرائجة».

## استعلامات GitHub المُثبتة (استعملها مدروسةً — لا تخترع متاهات)
| المجال | استعلام |
|---|---|
| مونتاج/تحرير فيديو | `video editing cli sort=updated stars>1000` · `moviepy OR pydub montage license:mit` |
| قصّ صمت/مقدم | `silence detect ffmpeg trim active` → نتائج: auto-editor مرفوض شبكيًا — بديلنا محلي ✓ |
| صوت عربي TTS | `piper arabic voice` · `arabic tts local onxx` — محصور HF (الجولة 2) |

| حملات OR-chestration | `marketing campaign agent framework MIT` — قرار: بناء ذاتي (campaign_run) |
| قياس/تحليل | `social media analytics dashboard python` — قرار: CSV يدوي+measure.py |
| مهارات وكلاء | `agent skills frontmatter SKILL.md` — معيار anthropics/skills مُتبنى كأنماط |

## بوابات التقييم الثلاث (بالترتيب — فشل الأُولى يوقف الباقي)
1. **الترخيص:** MIT/Apache-2.0/ISC/BSD → مقبول مبدئيًا. «NO-LICENSE» / «NOASSERTION» / غير مذكور → **رفض نهائي**. Unlicense مثل auto-editor: لا يرث شيئًا لكن كوده غير قابل للتشغيل شبكيًا أصلًا.
2. **التبعيات:** فحص requirements/setup — أعلم: تعارض pillow (معركة rembg) أو وزن كبير على HF (معركة piper/ليب-سينك) = رفض فوري بإثبات.
3. **الاختبار المعزول:** فيكستشر صغير حقيقي في `/tmp`، خارج مجلد المشروع، بمدى كامل قصير. الناجح يُدخل `engine/` ويُدخل `selfcheck` كفحص ويعاد تشغيله.

## التوثيق الإلزامي بعد كل جولة
- `studio/مخزون-الأدوات-المفتوحة.md`: سطر/جدول جديد بتاريخ اليوم — تبنّي/رفض/سبب/حدود.
- لو دمج: صف في `SKILL.md` جدول الأدوات + أمر في `commands/` + فحص `selfcheck` جديد.
- لو رفض: سبب مثبت (أول خطأ فعلي — لا تقل «تحت الماء» كناية عن التخمين).
- `02-التسويق/القياس-والتحسين/تقرير-الدفعة-<n>-<التاريخ>.md` للمالك*.

*ثم بلّغ المالك وفق قالب وكيل-ابدأ-هنا §7.
