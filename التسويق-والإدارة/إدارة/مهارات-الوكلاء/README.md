# مهارات وكلاء TerraNex (Agent Skills)

مهارات بصيغة **SKILL.md** القياسية المفتوحة — أي وكيل متوافق (Arena/Claude/Codex/Cursor وغيرهم) يقدر يقرأها ويشتغل بيها فورًا، وكلها شغالة **داخل بيئة الساندبوكس** من غير أي برامج عند المستخدم.

| المهارة | بتعمل إيه |
|---|---|
| `terranex-video-producer` | خط إنتاج الفيديو: فكرة/سكريبت/تفريغ/قصّ/كابشن/QA |
| `terranex-content-calendar` | تقويم محتوى وهوكات وكابشنات بدون تكرار |
| `terranex-owner-pitch` | عروض المالك والباقات والتفاوض |
| `terranex-lead-followup` | متابعة ليدز واتساب لحد الزيارة والعقد |

مكانها الدائم بالمشروع: `التسويق-والإدارة/إدارة/مهارات-الوكلاء/` على فرع `marketing-workspace-upload` — وتُحدّث مع كل درس جديد يتعلمه المشروع.
