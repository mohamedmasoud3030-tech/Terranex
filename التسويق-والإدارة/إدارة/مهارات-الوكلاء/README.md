# مهارات وكلاء TerraNex

> **آخر تحديث:** 18 أكتوبر 2026 — بعد مهمة الدمج والتوحيد.

## ✅ النظام الرسمي الوحيد

**`terranex-ops`** هو محرك التنفيذ الرسمي **الوحيد** لإنتاج محتوى TerraNex وإدارة التسويق والمبيعات.

**المكان:** `تسويق/مواد-وهوية/terranex-ops/`
**الإصدار:** 2.1.0 · **9 أوامر** · **5 ملفات سياق** · **9 محركات تنفيذ**

| الأمر | الوظيفة |
|---|---|
| `/idea` | أفكار المحتوى |
| `/script` | سكريبت فيديو |
| `/caption` | كابشن مصري |
| `/ad` | نسخ إعلانية |
| `/edit` | تصميم ومونتاج فعلي |
| `/review` | مراجعة قبل النشر |
| **`/pitch`** | **عرض المالك والباقات والتفاوض** *(مدموج)* |
| **`/leads`** | **متابعة ليدز واتساب** *(مدموج)* |
| **`/scenario`** | **سيناريو تصوري (Mock)** — نموذج عرض أثناء التجهيز، لا يُنشر |

## 📦 أرشيف المهارات المستبدَلة

انتقلت المهارات الأربع المنفصلة إلى `_مستبدلة/` بحالة **Superseded** — محفوظة للمراجعة التاريخية فقط، **لا تُفعّل ولا تُعدّل**.

| المهارة | الحالة | دُمجت في |
|---|---|---|
| `terranex-video-producer` | ⚠️ مستبدَلة | `terranex-ops` — قواعد الإنتاج في `SKILL.md` |
| `terranex-content-calendar` | ⚠️ مستبدَلة | `terranex-ops` — `/idea` + `/edit` |
| `terranex-owner-pitch` | ⚠️ مستبدَلة | `terranex-ops` — `/pitch` |
| `terranex-lead-followup` | ⚠️ مستبدَلة | `terranex-ops` — `/leads` |

> **سبب الدمج:** كان فيه 4 مهارات منفصلة + نظام `terranex-ops` = **5 أنظمة متنافسة** على نفس المهمة.
> ده كان بيخلق تعارضًا في النبرة والقواعد والهوية. دلوقتي مصدر واحد للحقيقة.

## لماذا لا تُستخدم المهارات القديمة

1. **تضارب هوية:** القديمة كانت بتشير لألوان ووسوم غير موحّدة.
2. **تضارب قواعد:** كل واحدة كان فيها نسخة مختلفة من «ممنوع وعود الأرباح».
3. **غياب البوابة:** مفيش تحقق آلي (`critic.py`) قبل التسليم.
4. **تكرار الحقيقة:** أي تعديل كان لازم يتعمل في 5 أماكن.

- **ممنوع** إضافة مهارة منفصلة جديدة بدون قرار صريح من المستخدم.
