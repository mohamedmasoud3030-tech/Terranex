# منتج فيديوهات TerraNex

## قبل ما تبدأ
1. اقرأ `إدارة/وثائق-المشروع/00-ملف-المشروع-الرئيسي.md` و`سجل-المحتوى.csv` وحدد المصادر المستخدمة قبل كده — ممنوع تكرار نفس المصدر بنفس الفكرة.
2. المادة الأساسية = صور وفيديوهات الشركة الحقيقية فقط. لا ستوك ولا توليد لمحتوى الصفحة (استثناء عرض المالك بموافقة صريحة فقط).

## خط الإنتاج
1. **الفكرة أولًا**: زاوية واحدة جديدة + هوك أول ثانيتين (سؤال/رقم/مفارقة). لا تبدأ من ريل جاهز أبدًا.
2. **السكريبت**: عربي طبيعي بلسان بشري، جمل قصيرة، مكتوب خصيصًا لـ TerraNex. لا نص إعلاني عام ولا صوت صناعي واضح.
3. **التفريغ**: شغّل faster-whisper محليًا (فكّ wav بـ wave+numpy ومرّر float32 — تمرير اسم الملف يفشل مع PyAV الحديث).
4. **القصّ**: مونتاج متقاطع من أكثر من مصدر عند الحاجة، تنويع مقاسات (9:16 للصفحة، 16:9 لعروض المالك)، وسم الشركة أسفل اللقطات موجود أصلًا — الكابشنات فوق أو نظيفة لا تزاحمه.
5. **النص العربي على الفيديو**: ارسم النص العربي الخام مباشرة بـ Pillow مع `anchor="ma"` وخط Amiri Bold. ممنوع arabic_reshaper فوق Pillow الداعم لـ libraqm (بيشوّه الحروف).
6. **الأدوات**: لا يوجد ffmpeg على النظام — استخدم باينري imageio-ffmpeg. الصور الثابتة تُدخل كإطار مفرد بدون `-loop` (zoompan مع loop بيضاعف الإطارات انفجاريًا). أنشئ مجلد الإخراج قبل أي تركيب.

## مراجعة الجودة (لازم كلها ✓)
- [ ] الفكرة والسكريبت والزاوية جديدة فعلًا مش عنوان جديد على ريل قديم
- [ ] لا مصدر مكرر من سجل المحتوى بنفس الاستخدام
- [ ] المهندس عبدالله ظاهر فقط لو بيخدم الفكرة
- [ ] لا وعود عائد/أرباح — ثقة وشفافية فقط
- [ ] معاينة إطارات (qa sheet) قبل التسليم + مدة/مقاس/سلامة صوت
- [ ] حدّث سجل المحتوى بالمصدر والفكرة بعد الاعتماد
