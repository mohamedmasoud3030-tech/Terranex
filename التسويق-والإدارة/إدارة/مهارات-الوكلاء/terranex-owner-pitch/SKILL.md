# عرض المالك والتفاوض — TerraNex

## هيكل العرض الرابح (60 ثانية منطوقة أو سلايدز)
1. **هوك**: «مستثمرك اللي جاي بيدوّر عليك دلوقتي… شايف اللي ظهر قدّامه» — المنافس الظاهر بيكسب الساكت.
2. **الألم**: صفحة ساكتة = فرص بتروح كل يوم.
3. **التشخيص**: «اللي ناقصك مش منتج، اللي ناقصك ظهور يليق بحجمك».
4. **النظام**: محتوى ثقة ← إعلانات ← واتساب ← زيارة مزرعة ← عقد. إحنا نظام مبيعات مش بوستات.
5. **إثبات**: نماذج شغل حقيقي (الفيديوهات المعتمدة) قبل الكلام عن المستقبل.
6. **خطة 90 يوم**: مراحل واضحة وتقرير أرقام دوري — القرار مبني على أرقام لا وعود.
7. **إغلاق**: سؤال واحد — «هنبدأ إمتى؟» وسكوت بعدها.

## قواعد التسعير والتفاوض
- فرّق دائمًا وبوضوح: أتعاب إدارة (لينا) ≠ ميزانية إعلانات (بتتدفع لـ Meta مباشرة).
- الباقات المرجعية بالمشروع: 8,000 / 14,000 (الموصى بها) / 22,000 جنيه شهريًا + ميزانية إعلانات مقترحة منفصلة 15–30 ألف — راجع أحدث ملف مشروع قبل استخدام أي رقم.
- ممنوع وعد بعائد أو ربح مضمون، وممنوع أرقام مخترعة. بع بالثقة والشفافية وخطة قابلة للقياس.
- عند اعتراض «غالي»: ارجع للـ 90 يوم بتقرير الأرقام وحق الإنهاء بعد التقييم.
- أي سكريبت صوتي للمالك يُقرأ بملمس بشري؛ التسجيل البشري يتركب على المونتاج الجاهز بنفس التوقيتات.
